# TOEIC Part 5 解説の追加項目：用語と書き方の決まり（2026-10-29）

`src/data/toeic/toeicPart5NotesRoundNN.ts` の「着眼点（h）」「ポイント（r）」「TOEICでのコツ（tip）」「手がかり（cues）」を書くときの決まり。
英文法の解説（`src/data/egV3Items.generated.ts`）と同じ用語・同じ語調にそろえる。ただし文面は写さない（型だけ参考にする）。

## 1. 役割を混ぜない

| 項目 | 画面の札 | 書くこと | 書かないこと |
|---|---|---|---|
| h 着眼点 | 緑の札「着眼点」 | 最初に**どこを見るか**（空所の前後の1語、文中の語句、選択肢の共通点など） | 答えそのもの・ルールの説明 |
| r ポイント | 赤の札「ポイント」 | **どう決まるか**。この問題を離れても使える一般化したルール | この文だけの話・実戦の手順 |
| tip TOEICでのコツ | 青の札「TOEICでのコツ」 | 本番で**どう使うか**（選択肢の見分け方、読む順番、時間の使い方） | 断定・効果の約束（「必ず」「頻出」「点が上がる」など） |
| cues 手がかり | 黄色のマーカー＋番号 | 問題文の中の根拠の語句。「正解の理由」に同じ語句（または対応する日本語）があるものだけ | 理由で触れていない語句 |

- 1項目は1〜2文。スマホ幅（360px）で3行以内（全角でおよそ60字まで。英字は半分で数える）。
- 同じ型の問題でも、その問題の文に出てくる語句を使って書く（文面の使い回しをしない）。
- 事実に確信が持てない問題は、追加項目を空のままにする（創作しない）。

## 2. 語調

- 常体・短文。体言止め可（既存の「正解の理由」と同じ）。例：「空所の直後は名詞 findings。」
- 英語の語句は英語のまま書き、前後に半角スペースを入れる。選択肢の記号（A〜D）は書かない（並びが回ごとに変わるため）。
- 「〜に注目。問われているのは〜」（英文法の着眼点の決まり文句）は使わない。

## 3. 用語（英文法の解説と同じ言い方）

| 使う言い方 | 使わない言い方 |
|---|---|
| 名詞・形容詞・副詞・動詞 | 名詞形・形容詞形（「〜形」は動詞の形にだけ使う） |
| 主語・目的語・補語・修飾語句 | 主部・目的部 |
| 節（主語＋動詞のまとまり）／句 | 文節 |
| 前置詞・接続詞・関係代名詞・関係副詞・先行詞 | つなぎ言葉 |
| 能動態・受動態 | 受け身形（「受け身」は説明の中で補足に使ってよい） |
| 現在形・過去形・現在完了・未来（will） | 現在時制形 |
| 動名詞（-ing形）・不定詞（to＋原形）・過去分詞・現在分詞 | ing形名詞 |
| 他動詞（目的語を直接取る）・自動詞（目的語を取らない） | |
| 可算名詞・不可算名詞 | 数えられる名詞（補足に使ってよい） |
| 単数扱い・複数扱い | |
| 主格・所有格・目的格・所有代名詞・再帰代名詞 | |
| 比較級・最上級・原級 | |

## 4. 使わない表現（検証スクリプトで機械的に止める）

必ず／絶対／頻出／よく出る／定番／確実／間違いなく／合格／満点／スコアが上がる／点が上がる／得点アップ／毎回出る
