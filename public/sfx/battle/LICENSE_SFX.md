# マナトビ 対戦効果音 ライセンス

## このフォルダの音（*.mp3）について

- `scripts/sfx/gen_battle_sfx.py` が numpy の数式だけで一から作ったオリジナル音です。
  サンプリング素材・フリー素材・他の人の音源・AIで生成した音声は、一切使っていません。
- 作ったときに第三者の権利が入り込んでいないので、**商用利用できます**。
  アプリへの組み込み、有料アプリ、広告、動画、配信にも使えます。
  改変・再配布もできます。クレジット表記は要りません。
- 権利は マナトビ（アプリの運営者）にあります。ほかの人の商用利用を止めたいときは、
  このファイルの一文を書き換えれば、それを利用条件にできます。

## 作り直し方

```bash
pip install numpy scipy        # ffmpeg も必要
python3 scripts/sfx/gen_battle_sfx.py
```

乱数のシードを固定しているので、何度実行しても同じ音ができます。
